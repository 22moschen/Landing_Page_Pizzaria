# **App Name**: PizzaZap

## Core Features:

- Interactive Pizza Menu: Display a scrollable menu of pizzas with photos, descriptions, and prices.
- Shopping Cart: Enable users to add items to a cart and view a summary of their order.
- WhatsApp Order: Generate a WhatsApp link with the order details to send to the pizzeria's number.

## Style Guidelines:

- Primary color: Tomato red (#FF6347) to evoke appetite and energy.
- Secondary color: Cream (#FFFDD0) to provide a soft, inviting background.
- Accent: Burnt orange (#CC7722) for buttons and interactive elements.
- Clean and readable fonts for menu items and descriptions.
- Simple, flat icons for categories and actions.
- Grid-based layout for the menu to showcase multiple pizzas at once.
